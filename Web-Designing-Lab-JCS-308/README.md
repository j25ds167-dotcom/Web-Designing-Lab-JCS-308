## Quick start
- HTML/CSS/JavaScript experiments: open the folder's `index.html` in a browser.
- React experiments (07 and frontend of 12): run `npm install`, then `npm run dev` inside the frontend/project folder.
- Express experiments (08, 09, 10 dynamic app, 12 backend): run `npm install`, configure environment variables where required, then `npm start`.
- Never commit `.env` files, passwords, API tokens, or database credentials.
