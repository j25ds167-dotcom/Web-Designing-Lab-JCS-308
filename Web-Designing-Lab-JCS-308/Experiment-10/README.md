# Experiment 10 — Cloud Deployment

## Static site (Netlify)
Import this repository in Netlify and set the publish directory to `static-site`. No build command is required.

## Dynamic app (AWS / supported Node host)
Set the project/root directory to `dynamic-app`, install dependencies, and use `npm start`. Configure `PORT` through the host. Test `/health`.

Deployment URLs are created by your hosting accounts; none are fabricated in this project.
